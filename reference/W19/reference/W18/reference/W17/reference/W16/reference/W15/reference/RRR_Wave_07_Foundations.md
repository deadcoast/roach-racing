### Build-level stat translation

The source image shows aggregate build readings. RRR derives corresponding behavior from actual components; it does not invent per-item source-game deltas or copy a 0–100 chart without its formula. [W07.S01]

| Source reading | RRR measure | Physical causes / scope |
|---|---|---|
| Speed | Achievable running pace | drive cadence + foot release + stride / leverage, limited by load and available supply. Free stride is a ceiling; a lap result is measured separately. |
| Acceleration | Rate of gaining speed | drive force × leverage, traction, supply and carried mass. No additional inherited acceleration gene duplicates those causes. |
| Grip | Available surface contact | clean purchase, loose purchase and contact load. Release is separately represented; high grip is not identical to fast stepping. |
| Cornering | Permitted speed and motion through a bend | surface contact, lateral structural allowance, radius and body geometry. Derived from the built system, not a flat cornering item bonus. |
| Balance | Corrective response and usable support | sensor latency, correction response, brace footprint, settling. Current path model is a bounded proxy, not full roll/inertia simulation. |
| Downforce | Speed-dependent hold-down | front surface coefficient and orientation; associated drag. Aero does not provide powered flight or low-speed magic grip. |
| Weight | Actual entry mass | native host, replacement accounting, physical parts counted once and reserve fill. Mass is normalized, not calibrated grams; consumed fuel does not yet update in-race mass. |

## 4. Meaningful combinations and alternative uses

**Glassline:** contact pads plus sensory stabilization. The feet provide purchase and release; the sensing assembly improves an available correction. No invisible set bonus.

**Lowstep:** torque musculature plus hip leverage plus structural support. The motor supplies output, the levers deliver it, and the frame supports the driven body.

**Last Laugh:** a full Hopper pair plus a separate reservoir and a separately sourced rebound organ. One larva cannot supply both the full reservoir and the full damper.

Each conversion tin is for the already-owned host. It must be bought, opened and assembled. A future complete-host kit remains a distinct product. [W07.S06]

**Alternative preparations:** Hoppers versus Springknees use the same hind source; Catchclaws versus Counterbraces use the same forelimbs; Fatbody versus Keel use the same tissue. **Disjoint preparations:** scarab drive versus support plates, mole hip levers versus toes, horn versus head plates can yield multiple honest products.
