# RRR — Wave v0.20
## Reference Cases and Physical Objects

**Working compendium edition.** Author premises govern; named amendments replace only their stated scopes. External research, historical experiments, new design and open author choices remain separate. No application or historical world state is changed.

These cases are desk-authored scenarios and visual briefs. They are not executed races, surgeries, economic simulations or player tests.

## Six connected paths

<a id="w20-path-novice"></a>

### One tin, one useful change, another race

`W20.PATH.NOVICE`

**Entry:** A new owner buys an ordinary Tin Can Special without breeding stock.

1. The owner fits the supplied contacts, names the host and uses the supported first meeting.
2. A later loose-surface run produces slipping. The result remains a real result, not a broken-tutorial screen.
3. At the ordinary bench, observations distinguish surface mismatch from damage. The owner can clean, reposition, obtain an actual alternative, or continue on the original suitable course.
4. The unused old contacts remain owned when actually removed. A stored comparison is not another physical build.

**Completed outcome:** A personally completed racer and an understood next construction remain usable.

**Adverse case:** A needed part may be unavailable or the owner may lose again. No entire breeding programme is introduced as the only way forward.

**Optional next interest:** Keep racing, collect appropriate stock, commission an adaptation, or finish a display.

<a id="w20-path-line"></a>

### A recoverable result becomes a precise breeding question

`W20.PATH.LINE`

**Entry:** An established Hopper line has useful return and source-paired timing.

1. Repeated difficult landings are compared against fit, supply and actual receiving contact before inheritance is blamed.
2. After a known worn receiving element is corrected, the maker still wants a different settling response at a declared demand.
3. The catcher seeks a complementary individual. Exact source quality remains uncertain until relevant observations or descendants supply evidence.
4. Ordinary offspring can supply suitable joint products or complete sets. Candidate replacements fill the maintained reserve rather than growing automatically.

**Completed outcome:** A real current-use improvement or a useful observed descendant is a complete milestone before the premium line is stable.

**Adverse case:** A failed brood or one-role cohort remains possible; no completed frame of a pedigree guarantees the desired pair.

**Optional next interest:** Supply a kit maker, continue selection, buy a measured assembly or stop new starts.

<a id="w20-path-maker"></a>

### The same sold kit returns as a customer’s project

`W20.PATH.MAKER`

**Entry:** A maker publishes an existing Glassline-style build and sources a separate kit.

1. Different actual stock supplies the product; the reference racer keeps its components.
2. The buyer assembles and finishes the delivered host. A later local appearance refers to that host, not a commemorative clone.
3. The recipient requests adaptation for another surface. Inspection distinguishes a new purpose from a defect inside the old promise.
4. A performed service returns the same host with actual replacement contact stock and the former parts handled by agreement.

**Completed outcome:** One valid delivery and one distinct, funded service can occur; no automatic repeated demand is assumed.

**Adverse case:** If the original supplied material failed its promise, a remedy is not disguised as another mandatory full-price sale.

**Optional next interest:** A new printed edition, another genuine buyer, or no further work.

<a id="w20-path-flyer"></a>

### A complete array and a local fault

`W20.PATH.FLYER`

**Entry:** A Skyhook owner uses a purchased complete Flyer rather than an owned pond.

1. A landing incident affects one root/interface, while the rest of the array and the host remain identified.
2. The return assessment separates contour, root response, yoke phase, supply and receiving anatomy.
3. A valid rematching service uses actual replacement stock and preserves the retained surfaces. Whole-insect repair research is not used to promise detached regeneration.
4. The new complete configuration receives an appropriate working assessment before another event.

**Completed outcome:** An honestly described working or limited-use array returns, or the owner chooses another actual project.

**Adverse case:** If the required rare core is irrecoverable and no compatible stock exists, ordinary service cannot create it.

**Optional next interest:** Use a ground racer, preserve the array, commission a replacement or seek suitable source stock.

<a id="w20-path-history"></a>

### Original material without mythical restoration

`W20.PATH.HISTORY`

**Entry:** A collector owns a recorded old horn core with a failed exchange interface.

1. The passport distinguishes the original core from the host and its remembered configuration.
2. The collector chooses display, working restoration or a separately funded replica.
3. A fitter supplies an actual new interface and tests the supported working direction; changed function is recorded.
4. The display label states what is original and what is new without turning that history into a power multiplier.

**Completed outcome:** A completed collection or working restoration is worth keeping on its own terms.

**Adverse case:** A lost original core cannot be recreated as authentic by a familiar pattern name.

**Optional next interest:** A performance build, a documented edition, or another visual collection goal.

<a id="w20-path-campaign"></a>

### An earned representative remains an owner

`W20.PATH.CAMPAIGN`

**Entry:** A qualified lanista has a host requiring repair before the next meeting.

1. Entrant eligibility, the host’s history and the prior heat build remain distinct.
2. The next meeting can receive a legitimately available different host; an active fixed-host meeting cannot be changed by relabeling a swap as repair.
3. W19 support covers its actual stated travel and receiving scope. Premium replacements are separate, and provider failure does not erase the earned result.
4. The original host is maintained or restored under an actual plan rather than sold automatically to finance the trip.

**Completed outcome:** The campaign has a clear sporting route and the stable remains a personal collection.

**Adverse case:** If the animal cannot continue an active meet and no published exception applies, that entry ends truthfully.

**Optional next interest:** Return to ordinary clubs, race another project, or pursue the next earned event.

## Ten physical-object briefs

<a id="w20-object-return-case"></a>

### The divided return case

`W20.OBJECT.RETURN_CASE`

**Construction:** A shallow host compartment sits beside numbered supports for recovered loose anatomy. The outline of each expected fitted component is a movable card, not a painted claim that it is present.

**Use:** On return, the owner can distinguish attached, retrieved, missing and already-loaned material. A restrained wing is supported by its root or permitted frame, not flattened for neatness.

**Misreading to prevent:** Contains actual stock; a drawn silhouette does not retrieve lost anatomy.

<a id="w20-object-work-slip"></a>

### The folded work-and-return slip

`W20.OBJECT.WORK_SLIP`

**Construction:** The front shows the animal or component, the requested use, the current observation and the chosen operation. Inside are the changed material and agreed limits.

**Use:** An ordinary job fits on the front. The detailed face opens only when there is a real discrepancy, special work or provenance question.

**Misreading to prevent:** Records performed work, not hidden genes or a guaranteed win.

<a id="w20-object-pair-bridge"></a>

### The rematching bridge

`W20.OBJECT.PAIR_BRIDGE`

**Construction:** Two independent root supports carry distinct donor marks; an adjustable common frame records the working relationship.

**Use:** A fitter can physically compare the pair while preserving which side was retained and which replaced.

**Misreading to prevent:** Matched does not mean same-source; two arbitrary arms are not matched until assessed.

<a id="w20-object-core-case"></a>

### The original-core cradle

`W20.OBJECT.CORE_CASE`

**Construction:** A robust support follows the retained horn or plate without requiring its failed living interface to carry the load. A second small well holds a separately tagged replacement.

**Use:** The original can be shown or restored without pretending the old root still works.

**Misreading to prevent:** No automatic restored strength; replicas and old fragments retain their own identities.

<a id="w20-object-sleeve-tray"></a>

### The indexed sleeve tray

`W20.OBJECT.SLEEVE_TRAY`

**Construction:** Small separated wells identify working travel and supported fit ranges, with one visible example joint demonstrating their actual purpose.

**Use:** A customer understands why a minor preparation can restore useful articulation without buying a whole drive.

**Misreading to prevent:** Sizes are functional ranges, not a species blacklist or universal better-bigger grade.

<a id="w20-object-pad-support"></a>

### The unloaded contact support

`W20.OBJECT.PAD_SUPPORT`

**Construction:** The hard rim carries the root/stalk while clearing the working face and compressible backing. Direction and previous service marks remain legible.

**Use:** The package does not perform an accidental long brake engagement during transport.

**Misreading to prevent:** Packaging protects the named material; it does not remove all aging or viability requirements.

<a id="w20-object-bill"></a>

### The retained-native assembly sheet

`W20.OBJECT.BILL`

**Construction:** The host is drawn once, retained native anatomy is visible, and supplied replacements are shown beside the actual locations they use. Removed material has its own note.

**Use:** The novice can see which essential functions already exist and what the kit adds.

**Misreading to prevent:** No missing native regrowth, duplicated part, hidden flight motor or undisclosed required purchase.

<a id="w20-object-regional-offer"></a>

### The regional service handbill

`W20.OBJECT.REGIONAL_OFFER`

**Construction:** A public board separates ordinary bench availability, booked specialist work, known source arrivals and actual meeting editions.

**Use:** The town feels like a recurring hobby community. Someone can choose one useful service without accepting every listed task.

**Misreading to prevent:** A pictured donor is available stock only when the seller actually has it.

<a id="w20-object-passport"></a>

### The layered racer passport

`W20.OBJECT.PASSPORT`

**Construction:** The current host image remains primary; detachable build/result slips show specific configurations. Separate core/repair annotations describe material history.

**Use:** Changing legs does not require renaming the animal; a past win can be traced without freezing its body forever.

**Misreading to prevent:** Ownership, eligibility and historical identity remain different claims.

<a id="w20-object-service-tin"></a>

### The supported first-use tin

`W20.OBJECT.SERVICE_TIN`

**Construction:** An illustrated complete racer is accompanied by protected real contents, initial support, fitting guide and a compact service card naming what is included.

**Use:** The owner opens a project worth building, with a usable return route after an ordinary problem.

**Misreading to prevent:** The card is not unlimited insurance, free anatomy or a substitute for a working kit.

## Twenty-eight editorial situations

<a id="w20-case-pad"></a>

**W20.CASE.PAD — A quick-release pad looks stiff after unsuitable holding.**

Check current material and contact; do not grant or remove inherited quality from its stiffness. Read [W20.CH.STATE](RRR_Wave_20_Foundations.md#w20-ch-state).

<a id="w20-case-empty"></a>

**W20.CASE.EMPTY — A rare reservoir is empty after a race.**

Retain the intact object and refill from actual supply if appropriate; no damage is inferred solely from contents. Read [W20.COMP.FATBODY](RRR_Wave_20_Component_Passports.md#w20-comp-fatbody).

<a id="w20-case-blocked"></a>

**W20.CASE.BLOCKED — A sound drive and full reservoir accompany a binding sleeve.**

The source need not be inferior; repair the actual linkage cause before a new breeding project. Read [W20.COMP.SLEEVES](RRR_Wave_20_Component_Passports.md#w20-comp-sleeves).

<a id="w20-case-loss"></a>

**W20.CASE.LOSS — A healthy racer misses the valid route.**

Retirement is a sporting outcome, not automatic injury or host death. Read [W20.CH.INCIDENT](RRR_Wave_20_Foundations.md#w20-ch-incident).

<a id="w20-case-win-damage"></a>

**W20.CASE.WIN_DAMAGE — A valid winner returns with local wing damage.**

Preserve its result; assess the actual material before future use. Read [W20.CH.INCIDENT](RRR_Wave_20_Foundations.md#w20-ch-incident).

<a id="w20-case-fracture"></a>

**W20.CASE.FRACTURE — An attractive repair looks closed but is untested for its former heavy load.**

Do not certify original strength from appearance; assess the needed function. Read [W20.CH.RECOVERY](RRR_Wave_20_Foundations.md#w20-ch-recovery).

<a id="w20-case-full-repair"></a>

**W20.CASE.FULL_REPAIR — Cleaning and rematching restore all relevant previous measurements.**

Do not add an unrelated permanent stat scar as a compulsory cost of repair. Read [W20.CH.RECOVERY](RRR_Wave_20_Foundations.md#w20-ch-recovery).

<a id="w20-case-core"></a>

**W20.CASE.CORE — A historic horn has an intact core and failed interface.**

A separately supplied compatible interface may restore use; original and new material stay distinct. Read [W20.CH.MEMORY](RRR_Wave_20_Foundations.md#w20-ch-memory).

<a id="w20-case-pair"></a>

**W20.CASE.PAIR — A replacement arm comes from another donor.**

If it can be fitted and matched, it is a valid mixed-source pair with both sources retained. Read [W20.COMP.CATCHCLAWS](RRR_Wave_20_Component_Passports.md#w20-comp-catchclaws).

<a id="w20-case-dual-tissue"></a>

**W20.CASE.DUAL_TISSUE — A seller offers the same fatbody as complete reserve and Keel.**

Allocation fails; separate actual material is necessary. Read [W20.COMP.KEEL](RRR_Wave_20_Component_Passports.md#w20-comp-keel).

<a id="w20-case-terminal"></a>

**W20.CASE.TERMINAL — A source drive was terminally extracted and its historical record persists.**

The record is not another living parent or a free repeat harvest. Read [W20.CH.RECOVERY](RRR_Wave_20_Foundations.md#w20-ch-recovery).

<a id="w20-case-route-mode"></a>

**W20.CASE.ROUTE_MODE — A quick trip and detailed trip return to the same cohort.**

Presentation depth does not create two independent copies of its individuals. Read [W20.CH.WORLD](RRR_Wave_20_Foundations.md#w20-ch-world).

<a id="w20-case-hidden"></a>

**W20.CASE.HIDDEN — Unknown stock has identical public evidence but different hidden potential.**

Default recommendations must not disclose the hidden difference by quoting an exact secret score. Read [W20.CH.SELECTION](RRR_Wave_20_Foundations.md#w20-ch-selection).

<a id="w20-case-research"></a>

**W20.CASE.RESEARCH — A low-return highly synchronized individual arrives at a missing-synchrony project.**

Retain its possible contribution without claiming the desired combined offspring already exists. Read [W20.CH.SELECTION](RRR_Wave_20_Foundations.md#w20-ch-selection).

<a id="w20-case-reserve"></a>

**W20.CASE.RESERVE — A successful producer has already filled its replacement target.**

A new brood does not automatically add another permanent protected pair. Read [W20.CH.SELECTION](RRR_Wave_20_Foundations.md#w20-ch-selection).

<a id="w20-case-work"></a>

**W20.CASE.WORK — The owner repeatedly previews placement and undoes the draft.**

No extra physical operation, resource use or elapsed care event happened merely through preview. Read [W20.CH.RETURN](RRR_Wave_20_Foundations.md#w20-ch-return).

<a id="w20-case-sale"></a>

**W20.CASE.SALE — A prior build sheet refers to a component that has since been sold.**

The record remains, but the component cannot be restored to inventory by loading the sheet. Read [W20.CH.PATTERNS](RRR_Wave_20_Foundations.md#w20-ch-patterns).

<a id="w20-case-moving-yoke"></a>

**W20.CASE.MOVING_YOKE — A fixed manually set phase is presented as automatic in-race adaptation.**

Reject the extra action unless actual adjustable mechanism and control are supplied. Read [W20.COMP.CROSSPHASE](RRR_Wave_20_Component_Passports.md#w20-comp-crossphase).

<a id="w20-case-root-brace"></a>

**W20.CASE.ROOT_BRACE — A strong brace prevents Kickback loading.**

Revise the working support path; the recovery organ cannot ignore rigid geometry. Read [W20.COMP.KICKBACK](RRR_Wave_20_Component_Passports.md#w20-comp-kickback).

<a id="w20-case-air-pad"></a>

**W20.CASE.AIR_PAD — An airborne racer has a powerful ventral brake.**

No ground contact means no pad braking; actual aero or propulsive changes govern aerial slowing. Read [W20.COMP.FELTBRAKE](RRR_Wave_20_Component_Passports.md#w20-comp-feltbrake).

<a id="w20-case-finance"></a>

**W20.CASE.FINANCE — A 60-credit workshop agrees to spend 64 before receiving a fee.**

Arrange an explicit staged receipt or new capital, or decline/change scope; no invisible overdraft. Read [W20.CH.ECONOMY](RRR_Wave_20_Foundations.md#w20-ch-economy).

<a id="w20-case-spare-host"></a>

**W20.CASE.SPARE_HOST — A qualified lanista needs another host between two separate meetings.**

A legitimately available host can be entered at the next meeting; the old one retains its history. Read [W20.CH.SPORT](RRR_Wave_20_Foundations.md#w20-ch-sport).

<a id="w20-case-mid-meet"></a>

**W20.CASE.MID_MEET — A component repair is used to disguise changing the fixed host mid-meet.**

Apply the published reserve-host exception or end that participation; no identity substitution. Read [W20.CH.SPORT](RRR_Wave_20_Foundations.md#w20-ch-sport).

<a id="w20-case-scale"></a>

**W20.CASE.SCALE — An artist requests final dimensions based on W19’s preferred study range.**

Keep it a proposal; dimensioned implementation requires the open decision to be selected. Read [W20.CH.DECISIONS](RRR_Wave_20_Foundations.md#w20-ch-decisions).

<a id="w20-case-regrowth"></a>

**W20.CASE.REGROWTH — A service resets condition and recreates a destroyed rare vein network.**

That is regeneration, not routine service; requires a separately authored approved mechanism and inputs. Read [W20.CH.RECOVERY](RRR_Wave_20_Foundations.md#w20-ch-recovery).

<a id="w20-case-offline"></a>

**W20.CASE.OFFLINE — The user leaves after stopping future broods.**

Default offline pause changes neither obligations nor profits; in-world care remains when time resumes. Read [W20.CH.ECONOMY](RRR_Wave_20_Foundations.md#w20-ch-economy).

<a id="w20-case-quote"></a>

**W20.CASE.QUOTE — Two methods meet the same specification, but one needs a new premium source.**

Offer the actual changed price before irreversible work; the customer may choose repair, alternative or no job. Read [W20.CH.ECONOMY](RRR_Wave_20_Foundations.md#w20-ch-economy).

<a id="w20-case-display"></a>

**W20.CASE.DISPLAY — A patterned repaired wing is unsuitable for its old race but beautiful.**

A display has a legitimate purpose under an honest label and actual care requirements. Read [W20.CH.MEMORY](RRR_Wave_20_Foundations.md#w20-ch-memory).
