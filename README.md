# RRR — Wave 20 Milestone Reference Pack

Start with [The Living Standard](docs/RRR_Wave_20_Foundations.md). This is a compendium edition, not a playable application.

**Working compendium edition.** Author premises govern; named amendments replace only their stated scopes. External research, historical experiments, new design and open author choices remain separate. No application or historical world state is changed.

The main current chapters are supported by [component passports](docs/RRR_Wave_20_Component_Passports.md), [products](docs/RRR_Wave_20_Product_Atlas.md), [explicit edits](docs/RRR_Wave_20_Milestone_Edit_Ledger.md), [resolution of broad decisiodocs/RRR_Wave_20_Resolution_Register.mdegister.md), [referendocs/RRR_Wave_20_Reference_Cases.mde_Cases.md) and [sodocs/RRR_Wave_20_Research.md_20_Research.md).

`RRR_Wave_20.spec` serializes the same authored records. `RRR_Current_Reference_v0.20.json` routes a current question to its exact record. `RRR_World_Context_v0.20.json` retains all prior records and appends the new volume. `reference/W19/` contains the complete unchanged previous pack, including its own nested historical reference.

The `.md` links work together in the extracted folder. No font files or source artwork are included. No runtime is changed, added or tested. See [editorial verification](docs/RRR_Wave_20_Editorial_Check.md) for the actual checks and evidence limits.
