# RRR — Wave v0.16 Reference Pack

## The Donor & Living-Material Atlas · Volume I

Start with [the main atlas](RRR_Wave_16_Foundations.md). Use [the subject map](RRR_Compendium_Map_v0.16.md) for particular questions.

**Contents:** 10 donor monographs; 8 material classes; all 30 W14 preparations indexed; 3 line-item livelihood sheets with 8 cases; 6 opportunity briefs; 8 physical-object briefs; 12 interpretation amendments; 15 research sources.

This is a compendium release. It contains no new game build, engine modification, playable content or human-study result. Fictional biology and prices are explicitly distinguished from narrow source observations. Absolute scale, broad loss/regeneration, detailed material durations and final economic calibration remain open.
