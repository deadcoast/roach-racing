## Scope boundary

Twenty full racing-source monographs now exist across W16–W18. Bankseed is a separately labeled support-stock note. W18 describes the complete flight construction, not just its wings; Kickback recovery is support-dependent; Boiler has actual finite contents and outlet geometry. The aerial layouts are qualitatively complete route/choice references, not scale-validated construction drawings. No new solver, player study, transplant experiment, budget simulation, sale or race result is claimed.

The external archive verification report is supplied separately so it is not circularly hashed inside its own archive.
