## Native exchange and scope

The fixture preserves native drive, hind-pair, reserve and front/middle-contact units in an identified bench cradle when replaced. Returning a prepared graft reinstalls that retained unit. It does not regrow tissue or create a new component. This is a restricted bench-release preparation profile, not a new global rule for pain, injury, graft removal or natural biology.

The primary drive interface, root bounds, part masses and normalization belong to the declared starter profile. RRR still permits broader engineered integration. Supporting geometry is checked with oriented root rectangles and layers, not full body/swept-limb physics.

## Exact foundation statements

### Draft, fitted host and physical custody

**Origin:** source_hobby_translation. **Refines:** W04.BENCH.04, W04.BIND.01.

**W05.BENCH.01** — A draft changes a proposed arrangement, not the host or current component custody.
Decision: Try a new build before committing. Consequence: The currently fitted racer remains available and unchanged.

**W05.BENCH.02** — A fitting commit validates the whole draft, then swaps the intended components together.
Decision: Fit an accepted layout. Consequence: A failure does not remove half a build or install a duplicate.

**W05.BENCH.03** — The same prepared sect identity may be loose, packaged or installed in the broader system, but never in two places at once.
Decision: Choose its present use. Consequence: A saved recipe is not an additional component.

**W05.BENCH.04** — Repeated fitting of an unchanged arrangement is a no-op.
Decision: Confirm or retry safely. Consequence: No second revision, duplicate anatomy or charge is created.

**W05.BENCH.05** — Replacement native units are explicitly retained in the W05 bench cradle.
Decision: Return an installed replacement. Consequence: The retained native unit is reinstalled; tissue is not regenerated.

**W05.BENCH.06** — This reusable preparation profile applies only to the declared bench experiment.
Decision: Select the branch explicitly. Consequence: W04 removal, injury and preservation decisions remain open elsewhere.

**W05.BENCH.07** — Returning a component in the draft does not yet make the fitted item loose.
Decision: Review removals before commitment. Consequence: Draft and installed readouts use different labels.

**W05.BENCH.08** — A whole multi-role Hopper assembly contributes mass and inventory once.
Decision: Use the paired unit rather than duplicated role slots. Consequence: Jump and landing capabilities do not create extra limbs.

**W05.BENCH.09** — A host retains its nameable identity across fitted versions.
Decision: Rebuild the same racer. Consequence: A new configuration is not a newly bred animal.

**W05.BENCH.10** — Any future payment or care commitment must attach to the actual fitting transaction.
Decision: Extend the fixture into the operating world. Consequence: Free session editing is not claimed as calibrated workshop economics.
