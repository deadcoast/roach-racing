## Coverage and remaining work

W19 supplies six settlement entries, four proposed factions, a representative charter, meeting templates, source/trade connections and three bounded histories. It does not finish global geography, final scale, broad life-course policy, numerical racing or all possible factions. All twenty earlier source monographs remain; the new directory does not count them as new biology.

`RRR_Wave_19.spec` contains this volume. `RRR_World_Context_v0.19.json` preserves all prior non-manifest data and appends W19. The complete original W18 reference tree is preserved under `reference/W18/`.
