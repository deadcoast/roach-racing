# RRR — Wave v0.16

## Living-Material Register: Thirty Existing Preparations

Read this as a lifecycle index, not a new list of equipment permissions. Each entry identifies the source anatomy and concurrent material needs. A structural core and a living root can share a component without sharing identical shelf behavior. Names refer to existing W14 preparations; full source monographs are provided for ten prioritized donors, while the remaining named sources stay on the authoring queue.
