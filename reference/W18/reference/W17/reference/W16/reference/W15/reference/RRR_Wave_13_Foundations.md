## Selected core and carried work

Wildlands is the deliberate Lucky 13 priority: spatial collecting previously existed primarily as quick route outcomes. It now gives the player approach, method, specimen and case decisions that alter the same stock used elsewhere. The earlier active-limb race task remains open; its source code is not rewritten or its acceptance claimed.

## Playable route

**10 · Wildlands → choose district, case and two tools → depart → choose a connected habitat → observe a visible individual → select a clear destination → approach quietly or quickly → place an appropriate ration/decoy or capture within tool reach → return → existing stock, breeding, assay, preparation, sale, maker or bench.**

A useful first route is Switchyard Reclamation → Split-sleeper bank, with a padded case and cup/sleeve. A grain ration can bring compatible insects toward a clear approach. It does not guarantee a catch. Clicking/keyboard-selecting a tile is a preview; movement needs its explicit action. Screens are uncertain clues.

## Shared identity and operating time

`canonical wild specimen → observed candidate → same animal in case → protected returned stock → existing breeder / sale / prepared anatomy → existing personal or commercial build → frozen race entry`

Four field beats advance one world turn; return settles a partial group. Departure and return each add one travel turn. The outing has 32 action beats. Reading or switching views consumes none. Home paid work is blocked until return, but established care, broods and opted-in automation advance with world time. Incoming case capacity is reserved before departure. Zero cash does not block return; existing care arrears remain visible.

## Limits and open acceptance

**Boundary:** A turn-based patch expedition with 3 district graphs and 12 nine-by-six boards, not a freely navigable continuous open world.

**Boundary:** Thirteen existing forms. No new species, extra lucky gene, mutation, linkage, learned behavior or inherited appearance implemented.

**Boundary:** Authored habitat probabilities, capture thresholds, action times and equipment are prototype parameters, not measured ecology or real handling instructions.

**Boundary:** Legacy quick-route plots and spatial patches are separate authored population sources; not one globally unified wildlife model.

**Boundary:** Current-world archive bounds still apply. Wild specimens remain records; long campaigns may reach the bounded archive and need subsequent compaction design.

**Boundary:** Field equipment is a loaned outing loadout bundled into the fee, not a complete gear-manufacturing or purchasing progression.

**Boundary:** No new paid exploration tasks or auto-selling scout results. Existing ordinary trade, selected orders and maker operations are used.

**Boundary:** Prepared tissue uses earlier stable-stock/reusable-collar rules. General storage decay, donor welfare, aging, regrowth and permanent loss remain earlier explicit decisions.

**Boundary:** Four-entry club rosters still use paired ground heats. Race operators remain byte-identical to W12; no airborne-fidelity improvement is claimed.

**Boundary:** Browser uses exact HTML after file navigation was blocked. Linux Chromium coverage does not establish Windows/macOS native-file storage, physical touch or human usability.
