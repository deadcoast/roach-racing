## Source-game completeness boundary

The current reference verifies the displayed core categories and selected real hobby mechanisms. It does not claim a complete source-game item-by-item census, per-item numerical effects, all installments, or every race prescription. Future item-level research must use inspected source evidence and distinguish actual source data from an authored RRR preparation.
